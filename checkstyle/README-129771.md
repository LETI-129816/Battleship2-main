## O que o Checkstyle não consegue verificar

O Checkstyle só valida a forma do nome (a expressão regular), e não o significado: `calcularPontos` e `xpto` cumprem o mesmo padrão, e um nome pode estar bem escrito mas enganar sobre o que o método faz. Também não distingue a língua usada nos nomes. Além disso, a action analisa só as linhas adicionadas no pull request, por isso violações que já existam no código não são assinaladas.
