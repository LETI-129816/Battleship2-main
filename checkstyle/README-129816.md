### Reflexão sobre as limitações do Checkstyle
O Checkstyle é uma ferramenta de análise estática extremamente eficaz para garantir a uniformidade sintática do código e o cumprimento estrito de convenções de formatação (neste caso, a regra `TypeName`, que obriga as classes a começarem por letra maiúscula). No entanto, a ferramenta é puramente estrutural e não consegue efetuar validações semânticas. Isto significa que o Checkstyle não consegue verificar se o nome escolhido é significativo, se faz sentido no contexto do domínio do jogo (Battleship), ou se descreve de forma clara e legível o propósito lógico da classe para os outros programadores.
